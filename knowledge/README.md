# Qumanity Knowledge Base

This folder contains all documentation for the Qumanity (Quantum Box) project.

## How to Use This Folder

| Folder | Contents | When to Refer |
| :--- | :--- | :--- |
| `01_identity/` | User types, age groups, zodiac, ID format | When adding user-related features |
| `02_routing/` | Geographic hierarchy, timelines, access rules | When building navigation or permissions |
| `03_stage_contracts/` | Rules: posts, voting, Qoins, karma | When modifying business logic |
| `04_references/` | Database schema, APIs, file structure | When debugging or adding new features |
| `05_artifacts/` | Built features, poems, logo, colours | When reviewing what exists |
| `06_development/` | Setup, deployment, Git, troubleshooting | When setting up or deploying |
| `07_cursor_rules/` | Reference to .mdc files for Cursor AI | For AI-assisted development |

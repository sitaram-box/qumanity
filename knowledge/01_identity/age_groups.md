# Age Groups (Ashrama)

## Four Stages of Life

| Group | Code | Age Range | Description |
| :--- | :--- | :--- | :--- |
| Balak | `B` | 0-24 years | Student / learning phase |
| Yuvak | `Y` | 25-49 years | Household / working phase |
| Vridh | `V` | 50-75 years | Retired / advisory phase |
| Sanyas | `S` | 75+ years | Renunciation / wisdom phase |

## Usage
- Age group is automatically calculated from `date_of_birth`
- Used for voting eligibility (13+ years)
- Used for nomination eligibility (Yuvak only for council elections)

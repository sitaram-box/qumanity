# User Types

## Overview
Qumanity has three main user types with different permissions and capabilities.

| Type | Code | Description | Can Vote? | Can Post? | Can Be Council? |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Human User | `H_U` | Real registered user | ✅ Yes | ✅ Yes | ✅ Yes |
| Demo User | `D_U` | Test/demo account | ✅ Yes | ✅ Yes | ❌ No |
| Admin | `H_U_ADMIN` | Super admin (Rohit Mudgal) | ✅ Yes | ✅ Yes | ✅ Yes (Mentor) |

## Account Type Upgrades
Admin can upgrade Human User accounts to:
- Volunteer
- Agent
- Manager
- Leader
- Mentor

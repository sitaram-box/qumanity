# Account Access Rules

## User Location Types

| Type | Birth in India | Present in India | Description |
| :--- | :--- | :--- | :--- |
| Type A | ✅ Yes | ❌ No | Indian living abroad |
| Type B | ❌ No | ✅ Yes | Foreigner in India |
| Type C | ❌ No | ❌ No | Foreigner abroad |
| Type D | ✅ Yes | ✅ Yes | Indian in India |

## Access Matrix

| User Type | Private | Personal | Public | Global | Zone Tab |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Type D | ✅ | ✅ | ✅ (present) | ✅ | ✅ |
| Type A | ✅ | ✅ | ✅ (birth only) | ✅ | ❌ |
| Type B | ✅ | ✅ | ✅ (present only) | ✅ | ❌ |
| Type C | ✅ | ✅ | ❌ | ✅ | ❌ |

## Notes
- Zone tab in Global Account only appears for users with India as birth or present location
- Public Account voting rights only for users whose present location is in India (Type B and D)

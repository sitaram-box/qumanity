# Karma Values

## Predefined Karma Actions

| Action | Rupee Value | Requires Verification | Requires Followup | Followup Days |
| :--- | :--- | :--- | :--- | :--- |
| Plant a tree | 10 | ✅ Yes | ✅ Yes | 180 |
| Teach 1 hour | 20 | ✅ Yes | ❌ No | 0 |
| Help elder (verified) | 15 | ✅ Yes | ❌ No | 0 |
| Report issue | 5 | ❌ No | ❌ No | 0 |
| Clean village area | 10 | ✅ Yes | ❌ No | 0 |

## Karma Claim Workflow
1. User submits karma claim with proof (photo, GPS, witness)
2. Village Council reviews the claim
3. If approved → Qoins credited to user's wallet
4. If rejected → user receives message with reason

## Tree Planting Special Rule
- 50% Qoins upfront (₹5)
- Remaining 50% after 6 months (if tree survives)
- User must upload survival photo at 6 months
- If tree dies, no further Qoins + karma penalty

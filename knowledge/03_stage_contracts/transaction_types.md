# Transaction Types

## Distribution Rules

| Type | Description | Distribution |
| :--- | :--- | :--- |
| Commercial | Buying/selling goods or services | 100% to seller |
| Donation | Voluntary contribution | 50% ethical return to donor + 50% split across levels |
| Contribution (karma) | Verified ethical action | New Qoins issued from governance container |
| Subscription | Premium features | 100% to kiosk container |

## Donation Split (50% portion)

| Level | Percentage of Donation Layer |
| :--- | :--- |
| Village | 20% |
| Tehsil | 20% |
| District | 20% |
| State | 20% |
| Nation | 20% |

## Karma Values

| Action | Rupee Value |
| :--- | :--- |
| Plant a tree (verified) | 10 |
| Teach 1 hour | 20 |
| Serve on Village Council (per day) | 50 |
| Report verified issue | 5 |

# Poems (Vinaya Patrika)

## Source
- **File:** `static/poems.json`
- **Total poems:** 237
- **Author:** Goswami Tulsidas
- **Book:** Vinaya Patrika

## Format

```json
[
    {
        "id": 1,
        "marker": "O राम [01]",
        "text": "श्रीरामचन्द्रजीकी जय हो..."
    },
    ...
]
```

## Usage
- Displayed in bottom marquee (scrolling ticker)
- Random start on each page load
- Sequential play (1 → 2 → ... → 237 → 1 → ...)
- Play/Pause button
- Left/right arrows to move within poem (when paused)

## Language
- All poems are in Hindi (Devanagari script)
- No translation – displayed as is

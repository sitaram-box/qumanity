# Logo

## File Location
`static/images/qumanity_logo.svg` (or `.png`)

## Design Elements

| Element | Description |
| :--- | :--- |
| Earth | Circular background representing planet Earth |
| White pigeon (dove) | Flying in front of the Earth |
| Colours | Saffron, white, green, navy blue |

## Symbolism

| Element | Meaning |
| :--- | :--- |
| Earth | Global reach, planetary consciousness, one family |
| White dove | Peace, freedom, hope, non-violence, humanity |
| Saffron | Courage, sacrifice, patriotism |
| White | Peace, truth, purity |
| Green | Earth, prosperity, growth |
| Navy blue | Trust, technology, depth |

## Usage
- Top-left corner of every page (header)
- Clickable → links to homepage
- Favicon (simplified version)

# Colour Palette

## Primary Colours

| Colour Name | Hex Code | Usage |
| :--- | :--- | :--- |
| Saffron (India) | `#FF9933` | Primary accent, buttons, active states |
| White | `#FFFFFF` | Text on dark backgrounds, backgrounds |
| Green (Earth) | `#138808` | Success messages, positive indicators |
| Navy Blue (Trust) | `#0A1929` | Primary text, dark backgrounds |
| Gold (Spiritual) | `#FFD700` | Highlights, special elements |

| Element | Background | Text |
| :--- | :--- | :--- |
| Body | `#0F172A` (slate-900) | `#F1F5F9` |
| Cards | `#1E293B` (slate-800) | `#F8FAFC` |
| Primary buttons | `#FF9933` (saffron) | `#000000` |
| Secondary buttons | `#3B82F6` (blue) | `#FFFFFF` |
| Danger buttons | `#EF4444` (red) | `#FFFFFF` |
| Marquee text area | `#FFFFFF` | `#000000` |
| "Oराम" button | `#000000` | `#FFFFFF` |
